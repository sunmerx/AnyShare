## 2. 关键机制与 AnyShare 挂点

### 2.1 接收流(信任模型主挂点)

```
发送端 HTTP → Rust 服务器(packages/core/src/http/server/v2.rs)
  ├─ check_pin()(common/pin.rs;pin_attempts 限次)
  └─ 通过 → 事件桥接 → Dart
        └─ app/lib/provider/network/server/controller/receive_controller.dart
             onPrepareUpload():
               ① selfRegister 过滤(指纹==本机证书)
               ② 建 ReceiveSessionState(senderFingerprint = event.certFingerprint,mTLS 不可伪造)
               ③ quickSave 判定块(L129–140)★:
                    - settings.quickSave(全局自动接收)
                    - quickSaveFromFavorites:发送方指纹 ∈ favorites → 自动接收(上游"信任设备"雏形)
                    - webUpload + receiveViaLinkAutoAccept
               ④ 未 quickSave → 弹 ReceivePage 等用户决定
```

**结论**:信任分级判定链插入 ③ 之前/之内;`favoritesProvider`(指纹+alias 列表,存 `ls_favorites`)扩展为带 `trust_level/owner/max_file_size/quota_*` 的信任条目即可,持久化仍走 shared_preferences。

### 2.2 限制执行的实现含义

Rust 已在 prepare-upload 完成接受前判定(PIN/单会话);Dart 侧控制"最终接受/拒绝"(`acceptFileRequest`)。**阶段一方案(零 Rust 改动)**:超限 → Dart 自动拒绝会话(发送端看到标准"已拒绝"),接收端本地 toast 说明原因 + 记历史;协议级 `FILE_TOO_LARGE/QUOTA_EXCEEDED` 错误体需改 Rust v2.rs,列为阶段二评估项(见 WP1-2 §5)。

### 2.3 发现

`scan_facade.dart StartSmartScan`:分阶段最省优先——① 组播通告(v2,UDP 53317)→ 收藏设备定向探测 → ② 1 秒宽限内无确认才做 legacy HTTP 全子网扫描(`StartLegacySubnetScan`)。`nearby_devices_provider.dart` 为 Redux 状态机(RegisterDeviceAction 等)。AnyShare 的 ownerId 展示只需扩展设备模型(announcement 新增字段 + `Device dto` 透传),扫描机制不动。

### 2.4 身份与安全

- mTLS;证书指纹 = SHA-256(cert);`securityProvider` 管 `StoredSecurityContext`(证书+指纹),变更即 `IsolateSyncSecurityContextAction` 同步到 Rust。
- PIN:接收端在设置中配置,Rust `check_pin` 校验并限次。AnyShare SAS 用于 AnyShare↔AnyShare 配对(扩展端口,Dart 实现),与 LocalSend 客户端交互仍走原 PIN。

### 2.5 Android 分享入口(上游现状 → 我们增强点)

- `share_handler` 插件;MainActivity `singleTask`;`cross_file_converters.dart` 把 share intent 转 SelectedFile。
- 已有:分享接收;**缺**:微信/QQ"用其他应用打开"(`ACTION_VIEW`)、直达选设备页的动线、批量 >500 优化、URI 过期兜底 —— Stage 3 增强清单的依据。

### 2.6 状态管理与 UI 骨架

- 状态管理:**Refena**(Redux 风格,非 Riverpod;DDD 7.2 的 Riverpod 假设作废,随上游)。
- i18n:自研方案(`assets/i18n/*.json` + `lib/gen/strings_*.g.dart` 生成);页面在 `lib/pages/`(含 about/settings/troubleshoot/progress/receive 等)。
- 上游已有 Windows 右键/自启/防火墙辅助:`util/native/context_menu_helper.dart`、`autostart_helper.dart`、troubleshoot 页内嵌 netsh 命令 —— Stage 3 桌面集成直接增强这些而非从零写。
