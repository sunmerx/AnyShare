# AnyShare UI 重设计:需求补全与界面设计

> 2026-10-17。产品定位已从"文件传输工具"演变为"**基于归属关系的局域网协作工具**"(文件共享 + 屏幕共享 + 键鼠共享 + 共享目录浏览)。本文重定信息架构与全部界面,替代现有 Receive/Send/Settings 三标签结构。配套可交互原型:`docs/ui-redesign/prototype.html`。

## 1. 产品定位(重述)

- **关系模型**:设备间关系有三种——同一归属者(我的设备)/ 已配对(设备列表)/ 拉黑(黑名单)
- **能力**:① 文件共享(发送文件到任意设备;接收;共享目录:设备主动开放目录,有权限的设备浏览取用)② 屏幕共享(E-2:Windows→Linux 投屏)③ 键鼠共享(E-2 模式 A:边缘穿越,实验性)
- **不做**:互联网中继、账号体系、云——一切都在局域网内,归属关系自持

## 2. 信息架构

```
侧栏(桌面)/底部导航(移动)
├── 我的设备     同一归属者的全部设备(含本机)
├── 设备列表     附近发现(未配对)+ 已配对设备(非本人归属)
├── 黑名单       被拉黑的设备
└── 设置         本机/接收/共享目录/屏幕共享/传输记录/网络/安全/关于

二级页面
├── 设备详情     身份、信任管理、操作区(发文件/投屏/键鼠/浏览目录)、拉黑
├── 共享目录浏览 对端开放目录的文件浏览器
├── 传输记录     发送/接收历史(设置内入口)
└── (现有)接收选项/网络接口/关于/问题排查/更新日志 等,样式对齐
```

## 3. 页面规格

### 3.1 我的设备

- 副标题:`归属者:<ownerName>`;说明:同一归属者的设备互相免确认
- **本机卡片置顶**(角标"本机"),不可发送/投屏(禁用态),可"浏览共享目录"(本机自身无此功能→隐藏)
- 卡片元素:平台图标、别名、平台+型号、在线状态(●在线 / ○ 离线+相对时间)、操作按钮:发送文件 / 共享屏幕 / 键鼠共享 / 浏览目录(按对端能力与信任显示)
- 空状态:仅本机时提示"其他设备安装 AnyShare 并设置为同一归属者后,将自动出现在这里"
- 点击卡片 → 设备详情

### 3.2 设备列表

两个分组:

1. **附近的设备**(发现中,未配对,可折叠):来自组播发现;操作:配对 / 直接发送文件(走接收方确认)
2. **已配对**:非本人归属的设备;卡片带信任徽章(临时/一般/完全);操作:发送文件 / 共享屏幕(临时信任→禁用,提示"临时设备不可投屏")/ 键鼠共享 / 浏览目录(对端开放且本机权限足够时)

- 顶栏:「**扫码配对**」按钮(F-PAIR-08/F-DISC-07):桌面展示二维码(地址+一次性令牌+指纹,60s 有效),手机扫码 → 双端按 SAS 确认配对
- 空状态(全部为空):"附近没有发现设备" + 排查帮助入口 + 扫码配对引导
- 点击卡片 → 设备详情

### 3.3 黑名单

- 列表:别名、平台、指纹(截断)、操作:解除拉黑 / 删除设备记录
- 被拉黑设备:不出现在设备列表;所有请求(传输/投屏/目录)一律拒绝
- 空状态:"没有被拉黑的设备"

### 3.4 设置

| 分组 | 内容 |
|---|---|
| 通用 | 主题/颜色模式、语言 |
| 本机 | 归属者名称、设备别名、本机指纹(复制) |
| 接收 | 保存目录、快速保存、图库保存、接收确认、完成通知 |
| 共享目录 | 开关 + 选择目录 + 权限范围(同归属者 + 完全信任) + 说明 |
| 屏幕共享 | 当前参数只读显示(1080p60 / 8Mbps)+ 参数选项禁用 + "即将开放"标注(D5) |
| 传输记录 | 入口 → 发送历史 / 接收历史 |
| 网络 | 网络接口白名单、防火墙排查入口 |
| 安全 | HTTPS 加密开关、指纹重置 |
| 关于 | 版本、开源许可、更新日志、问题排查、贡献者 |

### 3.5 设备详情

- 头部:大图标 + 别名 + 平台 + 在线状态
- 身份:归属者名、指纹(截断+复制)、地址(IP:端口)
- 操作区(主按钮):发送文件 / 共享屏幕 / 键鼠共享 / 浏览共享目录
- 信任管理:等级选择(临时/一般/完全)、单文件上限、容量限额、用量重置(现有 trust_settings_section 复用)
- **共享目录权限**:显示对端开放状态(只读/可写);完全信任设备在此开关「允许写入」(F-DIR-08)
- 危险区:拉黑设备(确认弹窗)/ 解除配对
- 该设备最近传输:3 条摘要 + "查看全部" → 传输记录过滤

### 3.6 共享目录协作(多设备文件管理器)

**核心诉求:多设备目录同屏浏览 + 完整文件操作 + 跨设备粘贴/拖放**(2026-10-18 需求升级,PRD F-DIR-01~10)。形态:左侧设备树 + 右侧文件面板(类资源管理器/FTP),**读写协作**:

**左侧设备树**
- 根节点 = **本机设备 + 全部已配对设备 + 附近设备**(均列出,方便选中文件后发送);开放了共享目录的设备可展开目录树,未开放/无权限的设备节点标注"可发送"图标
- 可**同时展开多台设备**的目录树,展开状态保留;在线/离线状态点(离线置灰,点击提示)
- **树可收起**(桌面:顶栏折叠按钮,提升浏览区空间利用率);**移动端:树默认隐藏,以左侧抽屉滑出**(顶栏汉堡键),选择后自动收起
- 选中文件后,树中各设备节点出现「发送到此设备」角标按钮(F-DIR-09);点击目录节点 = 浏览

**右侧文件面板**
- 顶栏工具区:面包屑(设备名 > 路径)/ 视图切换(列表 ⇄ 详细信息)/ **排序**(名称/大小/修改时间,升降序)/ **搜索**(当前目录,后续递归)/ **标签筛选**(下拉选标签过滤)/ 粘贴按钮(剪贴板非空时显示)/ 新建文件夹(可写时)
- **冲突处理**(F-DIR-14):粘贴/上传/拖放遇重名按设置策略;「每次询问」弹对比弹窗(保留两者/替换/跳过 + 应用于全部)
- **视图模式**(F-DIR-03):列表视图(紧凑单行:图标+名称+大小);详细信息视图(列:名称/大小/类型/修改时间);选择按设备记忆
- 条目:多选复选框、图标、名称、大小/时间;行尾「更多」菜单(右键同):预览、下载、复制、剪切、重命名、标签与备注、删除
- **预览**(F-DIR-04):图片 → 灯箱(上一张/下一张、缩放、下载、发送);Markdown → 渲染视图;预览快捷键空格(桌面)
- **文件操作**(F-DIR-05):复制/剪切后,切到任意设备目录点「粘贴」= 跨设备直传;删除需二次确认(F-DIR-10)
- **拖放**(F-DIR-06):面板/树之间拖拽条目(同设备 = 移动/复制,跨设备 = 传输);从系统拖入 = 上传到当前目录(高亮投放区)
- **标签与备注**(F-DIR-07):条目显示标签 chips;**备注文字直接可见**——详细信息视图设「标签与备注」列(标签图标 + 备注文字,单行截断、悬停看全文、点击进入编辑);列表视图在文件名后内联显示(标签 + 备注,截断);编辑入口不变(更多菜单/点击备注列);本机个人标注,不同步
- 只读目录:写操作(粘贴/删除/重命名/拖入)入口禁用并提示原因

**入口与状态**:设备卡片/详情"浏览共享目录"(聚焦该设备);本页返回来源设备详情;加载中/空目录/离线/只读/断连重试空态。

**说明**:一屏多设备树优于"每设备一个标签页"——多设备结构同时可见、可对照、切换零跳转;跨设备复制/粘贴/拖放即"设备间直传"(v1 经本机中转转发,协议复用 F-XFER 分块;直连优化后续评估)。

### 3.7 全局交互

- **传输面板**(F-XFER-16):左侧栏底部常驻「传输」区——活动传输(进度/速度/取消)+ 最近 3 条历史 + 「查看全部」→ 传输记录弹窗/页;移动端为底部浮标「传输中 n · 查看」;活动数角标
- **条目级发送**:目录条目的右键/更多菜单含「发送到…」(文件与文件夹、任意类型),选中多项时按多选发送(F-DIR-09 的条目级入口)
- **投屏请求弹窗**(接收端,limited/未知设备):"<设备名> 请求共享屏幕到本机" 接受 / 拒绝;full/同归属者免弹
- **投屏目标选择**(发送端):勾选式**多设备选择**;显示检测到的上行带宽与**建议并发数**(按 8 Mbps/台 估算,可重新测速);超过建议数弹「可能卡顿」提示(仍然继续 / 减少到建议值)(F-SCREEN-04/05)
- **投屏进行中**:接收端显示原生窗口(D1)+ 本机界面顶部状态条(对端名 + 计时 + 停止);发送端状态条显示**接收端数量**(多台时"N 台设备")+ 托盘提示(D4)
- **键鼠共享中**:状态条 + 热键紧急退出(默认 Ctrl+Alt+Shift+Esc,可改);剪贴板共享开关(默认开,F-KBMOUSE-02);**布局编辑器**(拖动调整屏幕相对位置,布局随会话保存,F-KBMOUSE-03);多设备编排(勾选多台)
- **防休眠/锁屏**(F-SYS-04/05):投屏/键鼠/传输进行时阻止休眠;锁屏自动断开共享会话
- **托盘状态**(F-SYS-02):图标呈现活动状态;菜单含 打开/断开全部(F-SYS-01)/退出
- **传输确认弹窗**:沿用现有流程,视觉对齐新卡片风格
- **拖拽文件到设备卡片**:直接发送(drag & drop 增强)
