## 铁律(违反会浪费大量时间)

1. 提交前:`dart format lib test` + `flutter analyze`(0 issues)+ `flutter test`(全绿)——CI 有 format 检查
2. 不动 Rust 层协议实现(rebase 成本);AnyShare 扩展一律做 Dart 层
3. 改 i18n 后跑 `dart run slang`;改模型后跑 `build_runner`;改视觉先出小样给用户确认(有过否决先例)
4. GitHub fork 怪癖:**push 不触发 workflows**,构建/检查用 `gh workflow run <name> --ref anyshare -R sunmerx/AnyShare` 手动派发;Windows 签名版 workflow 不可用(上游 Azure 账号),发布走 `build_windows_exe_unsigned.yml`
5. gh 大文件批量上传会 408 整体回滚 → release 资产**分步上传**
6. 版本号六处一致(CI 校验,当前 0.1.1,清单见交接文档 §4)
7. 上游 sync 监控:`git fetch upstream && git rev-list --count anyshare..upstream/main`(2026-10-15 预检 = 0)
