## 里程碑

1. **M1 = UI-1 + UI-2**:新壳可用,投屏可在 app 内发起/接收(设备面板→同意→出画)
2. **M2 = UI-3 + PAIR-1**:传输可见、扫码可配
3. **M3 = E3 全系列**:共享目录协作(最大块)
4. **M4 = MULTI-1 + SYS-1 + E2-收尾**:多设备共享与系统行为,进入 E2.1/E2.2 视野

- `home_page.dart`:四目标 NavigationRail/NavigationBar;落地页=我的设备;拖拽落文件 → 设备列表(选择设备发送)

- `pages/tabs/blocklist_tab.dart`(新):解除拉黑/删除记录
- `widget/device_card.dart`(新):统一卡片(状态/徽章/操作按钮组;动作回调注入)
- `util/device_groups.dart`(新):纯函数分组(我的/已配对/附近/黑名单)+ 单测
